# Техническое задание (черновик). WMS

## 1. Общие сведения
- Название: Система управления складом (WMS)
- Версия ТЗ: 0.1
- Стадия: проектирование, этап 1

## 2. Функциональные требования

### FR-01. Справочники
CRUD для категорий, единиц измерения, товаров, складов, ячеек,
контрагентов, пользователей.

### FR-02. Приёмка товара
Создание документа receipt. Указание поставщика, склада, ячейки, партии,
количества, цены. После проведения: инкремент stock.qty, запись movement in.

### FR-03. Перемещение
Документ transfer. Между ячейками одного склада и между складами.
Проверка достаточности остатка в источнике.

### FR-04. Списание
Документ writeoff. Причина: брак, порча, недостача.
Декремент остатка, движение out.

### FR-05. Инвентаризация
Документ inventory. Ввод qty_fact. Расчёт расхождения qty_fact - qty.
Автоматическое создание adjust-движений.

### FR-06. Отгрузка
Документ shipment. Проверка остатка перед списанием.

### FR-07. Штрих-кодирование
Генерация EAN-13 (12 цифр + контрольная сумма) и Code128.

### FR-08. Предупреждения о минимальных остатках
Проверка qty <= min_qty при каждом движении.
Представление v_low_stock.

### FR-09. Анализ оборачиваемости
avg_out_per_day за N дней. turnover_days = current_stock / avg_out_per_day.

### FR-10. Отчёты
Остатки на дату, движения за период, товары ниже min_qty, ABC-анализ.
