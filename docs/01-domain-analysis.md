# Анализ предметной области WMS

## 1. Назначение системы
Система управления складом (WMS) — ПО для автоматизации учёта
товарно-материальных ценностей на складе. Обеспечивает прослеживаемость
движения товара от приёмки до отгрузки, точность остатков и аналитику.

## 2. Границы предметной области
ВХОДИТ:
- Справочники: товары, категории, единицы измерения, склады, ячейки.
- Приёмка товара от поставщика.
- Перемещение между ячейками и складами.
- Списание (брак, порча, недостача).
- Инвентаризация.
- Отгрузка клиенту.
- Штрих-кодирование (имитация).
- Предупреждения о min-остатках.
- Отчёты и анализ оборачиваемости.

НЕ ВХОДИТ:
- Интеграция с 1С/ERP.
- Финансовый учёт.
- Управление закупками.

## 3. Бизнес-процессы
| № | Процесс | Входные данные | Выходные данные |
|---|---------|----------------|-----------------|
| 1 | Приёмка | Поставщик, товар, кол-во | Партия, движение in |
| 2 | Перемещение | Ячейка-источник, ячейка-цель | Движения move |
| 3 | Списание | Причина, товар, кол-во | Движение out |
| 4 | Инвентаризация | Факт. остатки | Акт расхождений |
| 5 | Отгрузка | Клиент, товар, кол-во | Движение out |
| 6 | Контроль остатков | Нормы min_qty | Список дефицита |
| 7 | Штрих-кодирование | SKU | EAN-13 / Code128 |
| 8 | Отчётность | Период, фильтры | Отчёты |
| 9 | Оборачиваемость | История движений | Коэффициенты |

## 4. Роли пользователей
| Роль | Права |
|------|-------|
| Администратор | Управление пользователями, справочниками |
| Менеджер | Просмотр остатков, отчёты, отгрузка |
| Кладовщик | Приёмка, перемещение, списание, инвентаризация |
| Аналитик | Просмотр отчётов, экспорт |

## 5. Ключевые сущности
- Товар (Product) — номенклатурная единица
- SKU — уникальный артикул
- Категория (Category) — группировка
- Склад (Warehouse) — место хранения
- Ячейка (Location) — адрес внутри склада
- Партия (Batch) — товар одной поставки
- Контрагент (Partner) — поставщик/клиент
- Документ (Document) — юридически значимая операция
- Движение (Movement) — иммутабельная запись
- Остаток (Stock) — агрегированное количество
- Штрих-код (Barcode) — идентификатор

## 6. Ограничения
- Товар может храниться в нескольких ячейках и партиях.
- Остаток не может быть отрицательным.
- Движения append-only.
- Штрих-коды генерируются имитационно.

## 7. Бизнес-правила
- BR-01: остаток нельзя списать ниже нуля.
- BR-02: приёмка всегда создаёт партию.
- BR-03: отгрузка невозможна при недостатке.
- BR-04: при qty <= min_qty создаётся предупреждение.
- BR-05: инвентаризация блокирует движения до утверждения.
